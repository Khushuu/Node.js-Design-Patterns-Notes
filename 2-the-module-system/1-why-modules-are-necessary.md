# Why Modules Are Necessary

- Module: actual piece of software.
- Module system: syntax and tools to define and use modules.
- Modules are the bricks for structuring non-trivial applications.
- Modules divide code base into small units for independent development and testing.
- Modules enforce information hiding by keeping non-exported functions and variables private.
- Modules make it easier to share and reuse code across projects.
- Good module systems should:
  - organize code across multiple files.
  - manage dependencies cleanly.
  - expose a clear public interface.
  - hide implementation details.
- Key benefit: modular structure improves maintainability, reuse, and encapsulation.
